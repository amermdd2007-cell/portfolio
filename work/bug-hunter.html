Bug Hunter, a game for learning to code

Players fix one bug a level in real code, in C++, Python, Java and more. I designed three versions of it and built every one in Flutter; it is live on Google Play.

Bug Hunter, screen by screen

bug-hunter.case· 7 steps

$ open bug-hunter --case-study

01
// before: v2.0

Players said it looked AI-made

Neon gradients, glowing cards and emoji everywhere. Some players did not believe a student had built it, so the look had to change, not the game.

04
// home

Home opens like a code editor

The next level waits in an editor tab with line numbers and the bug already marked. Players see code before they see a menu.

07
// paths

Languages as a file explorer

C++, Python, Java and the rest sit in an explorer tree with their progress, the way a programmer browses a project.

10
// game

The bug gets a red squiggle

The broken line has a breakpoint dot and a red squiggle, like a compiler warning. The output panel shows the real runtime error.

13
// result

Build passed, with the diff

Instead of confetti, the player gets what a developer gets: BUILD PASSED, the time, the points and the red and green diff of the fixed line.

16
// daily

A contribution graph for streaks

The daily bug keeps a grid of solved days in amber, the same graph programmers know from their code history.

19
// season

The season as a test run

Each week is a test: PASS in green, FAIL in red. 25 phone and 3 tablet screens, all built from the same 10 components.

01 / 07

Tablet and brand

The tablet splits the code and the task side by side. The logo is two code braces holding a bug.
